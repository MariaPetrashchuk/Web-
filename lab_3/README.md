
# Лабораторна робота №3

## Тема
Адаптивна верстка вебсторінки за допомогою Flexbox, CSS Grid та препроцесора SCSS.

## Мета роботи
Навчитися створювати адаптивні вебсторінки за допомогою сучасних технологій CSS, використовувати Flexbox і CSS Grid для розташування елементів, а також застосовувати SCSS для організації та повторного використання стилів.

## Використані технології
- HTML5
- CSS3
- Flexbox
- CSS Grid
- SCSS (Sass)
- Media Queries
- Visual Studio Code
- Live Sass Compiler
- Git та GitHub

## Хід виконання роботи

### 1. Підготовка проєкту
Для виконання лабораторної роботи використано вебсайт «Акустична варта», створений у лабораторній роботі №2.

Створено окрему папку `lab_3`, у якій розміщено HTML-файл, зображення, CSS та SCSS.

### 2. Створення SCSS-структури
Стилі вебсайту розділено на окремі модулі:

- `_variables.scss` — змінні кольорів, відступів і розмірів.
- `_mixins.scss` — міксини для повторного використання стилів.
- `_base.scss` — базові стилі сторінки.
- `_layout.scss` — розташування основних блоків.
- `_components.scss` — стилі компонентів.
- `main.scss` — головний файл підключення модулів.

Для підключення модулів використано директиву `@use`.

### 3. Використання Flexbox
Flexbox застосовано для:
- шапки сайту;
- навігаційного меню;
- карток;
- нижнього колонтитула.

### 4. Використання CSS Grid
CSS Grid застосовано для:
- головного банера;
- карток поточного моніторингу;
- карток послуг;
- форми замовлення.

### 5. Реалізація адаптивності
Адаптивну верстку реалізовано за принципом Mobile First.

Передбачено три режими відображення:

| Пристрій | Ширина екрана |
|---|---|
| Mobile | До 767 px |
| Tablet | 768–1023 px |
| Desktop | Від 1024 px |

Картки моніторингу відображаються:
- Mobile — 1 колонка;
- Tablet — 2 колонки;
- Desktop — 5 колонок.

Картки послуг відображаються:
- Mobile — 1 колонка;
- Tablet — 2 колонки;
- Desktop — 4 колонки.

Таблиця вимірювань має горизонтальну прокрутку на малих екранах.

Форма замовлення змінює кількість колонок залежно від ширини екрана.

### 6. Компіляція SCSS
За допомогою Live Sass Compiler виконано компіляцію файлу `main.scss` у `css/main.css`.

Отриманий CSS-файл підключено до HTML-документа.

### 7. Перевірка адаптивності
Для перевірки верстки використано інструменти розробника браузера.

Контрольні ширини:
- 375 px;
- 768 px;
- 1024 px;
- 1200 px.

## Висновок
Під час виконання лабораторної роботи створено адаптивну версію вебсайту «Акустична варта». Використано Flexbox для гнучкого розташування елементів, CSS Grid для побудови сіток та SCSS для модульної організації стилів. Реалізовано адаптацію основних компонентів для мобільних пристроїв, планшетів і комп'ютерів.
