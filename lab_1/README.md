# Лабораторна робота №1

## Тема: Імплементація блогу «Мої 3 найкращі міста світу». Розміщення проєкту в репозиторії GitHub

**Дисципліна:** WEB-програмування

## Мета роботи

Набути практичних навичок створення багатосторінкового статичного вебсайту за допомогою HTML, організації структури проєкту, використання семантичної розмітки, створення навігації та HTML-форм, а також роботи з Git, GitHub і GitHub Pages.

## Виконання роботи

### 1. Створення структури проєкту

Створено папку `lab_1`, у якій розміщено HTML-файли, папку із зображеннями та файл README.md.

Структура проєкту:

```text
lab_1/
├── images/
│   ├── lviv.jpg
│   ├── paris.jpg
│   └── tokyo.jpg
├── city-lviv.html
├── city-paris.html
├── city-tokyo.html
├── form.html
├── index.html
└── README.md
```

### 2. Реалізація головної сторінки

У файлі `index.html` створено головну сторінку блогу «Мої 3 найкращі міста світу».

На головній сторінці представлено три міста:

1. Львів — Україна.
2. Париж — Франція.
3. Токіо — Японія.

Для організації структури використано семантичні HTML-елементи `header`, `nav`, `main`, `section`, `article` та `footer`.

### 3. Створення сторінок міст

Для кожного міста створено окрему HTML-сторінку:

- `city-lviv.html` — інформація про Львів.
- `city-paris.html` — інформація про Париж.
- `city-tokyo.html` — інформація про Токіо.

Сторінки призначені для відображення опису міст, цікавих фактів, визначних місць та фотографій.

### 4. Реалізація навігації

Для переходів між сторінками використано HTML-елемент `<a>` з атрибутом `href`.

Відносні посилання забезпечують навігацію між головною сторінкою, сторінками міст та формою.

### 5. Додавання зображень

У папці `images` розміщено фотографії трьох міст.

Для підключення зображень використано HTML-елемент `<img>` з атрибутами `src` та `alt`.

### 6. Створення HTML-форми

У файлі `form.html` передбачено форму «Запропонувати місто для наступного рейтингу».

Для створення форми використовуються стандартні HTML-елементи: `form`, `label`, `input`, `select`, `option`, `textarea` та `button`.

### 7. Використані технології

- HTML5 — створення структури вебсторінок.
- Git — контроль версій проєкту.
- GitHub — зберігання вихідного коду.
- GitHub Pages — публікація статичного вебсайту.
- Visual Studio Code — редагування файлів.

## Висновок

Під час виконання лабораторної роботи було розглянуто принципи створення багатосторінкового статичного вебсайту за допомогою HTML. Створено структуру блогу «Мої 3 найкращі міста світу», що містить головну сторінку, окремі сторінки міст та HTML-форму. Закріплено навички використання семантичних елементів, відносних посилань, зображень та організації файлів вебпроєкту.
