
# Лабораторна робота №2

## Тема
Верстка сайту компанії згідно з інструкцією (HTML/CSS).

**Дисципліна:** WEB-програмування

## Мета роботи
Практично застосувати CSS для оформлення семантичної HTML-структури вебсторінки, навчитися підключати зовнішні таблиці стилів, використовувати CSS-селектори, каскад, специфічність, Box Model та властивість display.

## Виконання роботи

### 1. Створення структури проєкту
Створено папку lab_2, яка містить HTML-документ, зовнішню таблицю стилів CSS, зображення та README.md.

### 2. Реалізація HTML-структури
Розроблено односторінковий сайт компанії «Акустична варта».

Використано семантичні елементи:
- header;
- nav;
- main;
- section;
- article;
- aside;
- footer.

### 3. Створення основних секцій
На сторінці реалізовано:
- головний банер компанії;
- блок поточного моніторингу;
- картки напрямів роботи;
- попередження про підвищений рівень шуму;
- таблицю останніх вимірювань;
- форму замовлення дослідження;
- нижній колонтитул.

### 4. Підключення CSS
Створено зовнішній файл css/style.css.

Підключення виконано за допомогою:

<link rel="stylesheet" href="css/style.css">

### 5. Використання CSS-селекторів
У роботі застосовано:
- селектори елементів;
- селектори класів;
- селектори ID;
- селектори атрибутів;
- універсальний селектор;
- групування селекторів.

### 6. Каскад і специфічність
Продемонстровано конфлікт CSS-правил для активного посилання навігації.

Правило `.site-header nav a.active` має більшу специфічність, ніж `nav a.active`, тому його значення кольору має пріоритет.

### 7. Box Model
Для оформлення карток і секцій використано width, height, padding, margin, border та box-sizing: border-box.

### 8. Властивість display
Використано display: block, inline-block, flex та grid.

Картки моніторингу й послуг оформлено через display: inline-block.

### 9. Positioning, Transform і Transition
Для попередження використано position: relative, для позначки — position: absolute.

Для кнопок і карток додано transition та transform, що забезпечують плавні візуальні ефекти під час наведення.

### 10. Перевірка роботи
Проєкт призначений для перевірки у браузері та через DevTools. JavaScript і CSS-фреймворки не використовуються.

## Висновок
Під час виконання лабораторної роботи розроблено односторінковий вебсайт компанії «Акустична варта» за допомогою HTML5 і CSS3. Закріплено навички створення семантичної структури, підключення зовнішніх стилів, застосування селекторів, Box Model, каскаду та специфічності CSS. Реалізовано оформлення карток, таблиці, форми та адаптивне відображення сторінки.
